# 케셰브 실행 안내 한 장 (STUDENT_ONE_PAGE_GUIDE)

처음 보는 사람이 이 한 장만 보고 앱을 켜 볼 수 있게 쓴 안내입니다. 더 자세한 설명은 `docs/STUDENT_RUNBOOK.md`에 있습니다.

**케셰브(KESHEV-Cloudy)는 무엇인가요?** 내 PC에서 켜서, 이 PC의 CPU·메모리·디스크와 네트워크·방화벽 설정, Windows 경고·오류 건수를 **읽기만** 해서 보여 주는 앱입니다. PC 설정을 바꾸지 않고, 읽은 값을 어디로 보내지도 않습니다. 회사 시스템(SDP 서버)에는 연결하지 않은 채로 켭니다.

## 준비물 (처음 한 번만)

| 필요한 것 | 확인하는 방법 | 이렇게 나오면 됩니다 |
|---|---|---|
| Windows PC | — | — |
| Node.js 22~24 | CMD에서 `node --version` | `v22.…`, `v23.…`, `v24.…` 중 하나 |
| Git | CMD에서 `git --version` | `git version …` |

없으면 Node.js(https://nodejs.org)와 Git(https://git-scm.com)을 설치하고 **CMD 창을 새로 연 뒤** 다시 확인합니다.

## 켜는 순서 (아래 줄을 한 줄씩 복사해서 실행)

1. CMD를 엽니다(시작 메뉴에서 `cmd` 검색).
2. 받을 위치로 이동합니다(바탕화면).
   ```
   cd /d %USERPROFILE%\Desktop
   ```
3. 앱을 받습니다.
   ```
   git clone https://github.com/SCA-cloudy/KESHEV-Cloudy.git
   ```
4. **앱 폴더**로 들어갑니다. 앱은 `KESHEV-Cloudy` 안의 `on-client` 폴더에 있고, 아래 명령은 반드시 이 폴더에서 실행합니다.
   ```
   cd KESHEV-Cloudy\on-client
   ```
5. 코드를 검사합니다. 아무 오류 없이 끝나야 합니다.
   ```
   npm run check
   ```
6. 앱을 켭니다.
   ```
   npm start
   ```
   `케셰브 연결 확인: http://127.0.0.1:5189`가 나오면 켜진 것입니다. 이 CMD 창은 앱이 켜져 있는 동안 닫지 마세요. 별도 설치(`npm install`)는 필요하지 않습니다.
7. 브라우저(크롬 등)에서 이 주소를 엽니다.
   ```
   http://127.0.0.1:5189
   ```
8. 화면에서 확인합니다.
   - 위쪽의 **"연결 없음"** 표시와 빨간 안내는 **정상**입니다. 회사 시스템에 연결하지 않았다는 뜻입니다.
   - 화면 맨 위의 제공 카드 「내 PC 상태」는 PC의 현재 CPU·메모리·디스크를 보여 줍니다(「내 PC 확인」 버튼).
   - 화면을 아래로 내려 「학생 상태·알림 표시」 카드(현재 로그인·학생 구현 표시·내 기기·내 세션 다음)에서 「내 PC 점검」을 찾아 **「PC 값 조회」를 한 번** 누릅니다.
   - 「② 최근 기록」에 조회 한 줄이 생기고, 아래 「연결과 기록」에 네트워크·방화벽·Windows 경고·오류가 채워지면 성공입니다. 「다시 조회」를 한 번 더 누르면 직전과의 비교와 「③ 변화」 막대가 나옵니다.
9. 끄기: 앱을 켠 CMD 창을 클릭하고 `Ctrl+C`를 누른 뒤 `Y`를 입력합니다.

## 막혔을 때

| 이렇게 나오면 | 이렇게 합니다 |
|---|---|
| `'node'은(는) 내부 또는 외부 명령…` 또는 `node is not recognized` | Node.js를 설치하고 CMD 창을 새로 연 뒤 다시 합니다. |
| `'git'은(는) 내부 또는 외부 명령…` | Git을 설치하고 CMD 창을 새로 연 뒤 다시 합니다. |
| `node --version`이 v22~v24가 아님 | 이 안내는 v22~v24에서만 따라 해 봤습니다. 그 범위의 Node.js를 설치합니다. |
| `npm error`와 `package.json`을 찾을 수 없다는 글 | `on-client` 폴더가 아닌 곳에서 실행한 것입니다. 4번의 `cd KESHEV-Cloudy\on-client`부터 다시 합니다. |
| `EADDRINUSE`(포트가 이미 사용 중) | 다른 번호로 켭니다. `set ON_PORT=5190`을 실행한 뒤 `npm start`를 하고, 브라우저 주소 끝을 `:5190`으로 바꿉니다. |
| 브라우저에서 주소가 열리지 않음 | 앱을 켠 CMD 창이 켜져 있는지, 주소가 `http://127.0.0.1:5189`인지 확인합니다. |
| 「학생 상태·알림 표시」 카드가 안 보임 | 제공 카드 아래에 있습니다. 화면을 아래로 내립니다. |
| 「PC 값 조회」 뒤 빨간 상자가 나옴 | 상자 안의 "무엇이 안 됐나"와 "다음에 할 일"을 따릅니다. |
| 일부 항목이 `확인 불가`로 나옴 | 오류가 아닙니다. 못 읽은 값을 0이나 정상으로 꾸미지 않고 `확인 불가 (이유)`로 보여 주는 것입니다. |
| `ExperimentalWarning: SQLite …` 줄(Node 22) | 경고일 뿐 오류가 아닙니다. 그대로 두면 됩니다. |

## 이 앱이 하지 않는 것

- PC의 방화벽이나 보안 설정을 바꾸지 않습니다. 읽기만 합니다.
- 읽은 값을 인터넷이나 AI로 자동으로 보내지 않습니다.
- 버튼을 누를 때만 값을 읽고, 자동으로 반복해서 읽지 않습니다.
